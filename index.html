Interactive Concept Laboratory

Test real networking algorithms with custom parameters, step-by-step execution, and live state visualization.

1. CRC (Cyclic Redundancy Check) Generator & Verifier

Performs Modulo-2 polynomial division (XOR division) to calculate FCS remainder and verify received frames (solves CST303 Dec 2023 Q14b).

2. Sliding Window Protocol Simulator

Interactive Go-Back-N, Selective Repeat, and Stop-and-Wait flow control with ACK loss simulation.

3. IPv4 Subnetting & CIDR Calculator

Solves university subnetting numericals (e.g. 181.56.0.0 for 1000 subnets).

4. Shortest Path Router (Dijkstra SPF)

Calculates shortest paths and routing table next-hops across a 6-node enterprise network.

Portfolio Project Blueprint & Interview Talking Points

Why this project stands out to recruiters:

Unlike generic web apps, NetPulse bridges classical Computer Science graph theory (Dijkstra SPF) with real-world enterprise networking (OSPF, SDN controller design, and Cisco IOS automation).

Key Interview Talking Points:
  • ✔ "Demonstrates path recalculation after a single-link failure in a simulated topology."
  • ✔ "Generates Cisco 2811 IOS router configuration scripts automatically for the lab topology."
  • ✔ "Shows simulated telemetry: packets sent, delivered and dropped, and per-packet latency."
